# 修仙系统互动模拟游戏（网页版）

一个可直接打开游玩的纯前端修仙互动模拟游戏：融合文字冒险、养成、投资返利、宗门与世界事件。

## 运行方式

无需安装依赖。

- 直接双击 `index.html` 在浏览器打开；
- 或在项目目录执行任意静态服务器（推荐）：

```bash
python3 -m http.server 5173
# 浏览器访问 http://localhost:5173
```

## 已实现玩法

- 系统对话与指令解析（修炼/闭关/探索/炼丹/炼器/副本/突破/加入宗门/前往/投资）
- 境界成长与突破判定（修为、材料、心境、风险、失败Debuff）
- 天骄投资返利系统（忠诚/野心/魔性/感恩/成长，含叛变概率）
- 地图与宗门面板（控制权与世界态势变化）
- 时间系统（每 40 秒推进 1 个时辰）
- 世界事件库（> 250 条，支持随机+条件触发+冷却）
- 对话区与事件区自动滚动

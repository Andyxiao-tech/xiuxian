# 修仙系统互动模拟游戏（网页版）

一个可直接打开游玩的纯前端修仙互动模拟游戏：融合文字冒险、养成、投资返利、宗门与世界事件。

## 运行方式

无需安装依赖。

- 直接双击 `index.html` 在浏览器打开；
- 或在项目目录执行静态服务器：

```bash
python3 -m http.server 5173
# 浏览器访问 http://localhost:5173
```

## 第二轮优化（已完成）

- 事件库外置为独立数据文件：`events-data.js`（前端运行）+ `events.json`（数据源格式）
- 新增完整事件总表：`EVENTS_CATALOG.md`（逐条列出全部事件，便于你审阅与补充）
- 游戏逻辑改为读取外置事件库，支持持续扩展事件而不改核心逻辑

## 数值因果链（持续生效）

- 心魔印记 / 伤势：降低行动收益、降低突破率、抬升反噬概率
- 功德 / 因果：影响天劫压力、周结算质量、事件走向
- 道心 / 灵力纯度：影响突破门槛、炼丹质量、失败代价
- 地图修正：不同区域对收益/风险/成本产生不同系数
- 事件抉择：每个事件都通过选项写回角色与世界状态

## 主要指令

- 行动：`修炼` `闭关` `探索` `炼丹` `炼器` `探秘副本` `突破` `渡心劫`
- 交互：`加入宗门 青岚宗` `前往 落月秘境` `投资 林清雪 200` `帮助`
